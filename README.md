# Toolkit — 24 small tools

One single HTML file with 24 small, useful tools in one place. Open it in any browser and start using them — no build step, no installation, no account needed.

## How to run

1. Download `Toolkit___24_small_tools.html` from this repository.
2. Open it in any modern browser.
3. Pick a tool from the sidebar, use it, and come back any time — your To-Do items and Notes are saved in your browser.

That's it. There is nothing to install and nothing to set up.

## The 24 tools

### Time
- **Digital Clock** — live time and date
- **Analog Clock** — moving clock hands
- **Stopwatch** — start, pause, reset

### Productivity
- **To-Do List** — add, edit, delete and tick off tasks (saved in your browser)
- **Notes App** — save and edit notes (saved in your browser)
- **Countdown Timer** — custom countdown

### Health & Money
- **Age Calculator** — exact age from a date of birth
- **BMI Calculator** — health metric calculator
- **Tip Calculator** — restaurant tips, split between people

### Math
- **Calculator** — basic arithmetic
- **Unit Converter** — length, weight, temperature
- **Random Number** — generate a number in a range

### Security
- **Password Generator** — random secure passwords
- **Strength Checker** — weak/strong indicator for a password
- **Login & Signup UI** — form validation demo only (no real sign-in, nothing is sent or stored)

### Text
- **Word Counter** — words and characters
- **Character Limit Checker** — live character count
- **Random Quote** — random quotes

### Fun & Design
- **Color Picker** — generate HEX/RGB colors
- **Background Changer** — dynamic backgrounds
- **Counter** — increment/decrement

### UI Components
- **FAQ Accordion** — expand/collapse questions
- **Image Slider** — previous/next images
- **Responsive Navbar** — mobile hamburger menu

## Notes

- **Light and dark mode:** the page follows your system theme.
- **Your data stays with you:** To-Do items and Notes are stored only in your own browser's local storage. Nothing is uploaded anywhere.
- **Login & Signup is a demo:** it only shows form validation. It does not create an account or send your details anywhere.
- The page loads its display fonts from Google Fonts, so the exact typeface may fall back to a system font when you are offline. Every tool still works offline.
